# C Language From Basics — 1,000+ Programs

This pack contains **1290 standalone `.c` files**, organized into topic folders.

## Learning order
1. Hello World and output
2. Variables and data types
3. Input and operators
4. If/else and switch
5. Loops and number programs
6. Pattern printing
7. Functions and recursion
8. Arrays
9. Strings
10. Pointers
11. Structures
12. File handling
13. Math and number theory
14. Searching and sorting
15. Matrices
16. Bitwise operations
17. Mini programs
18. Practice starter templates

## Compile and run
Install GCC (for example, MinGW-w64 on Windows). Open a terminal in the folder containing the `.c` file:

```bash
gcc 0001_Hello_World.c -o program
```

PowerShell:
```powershell
.\program.exe
```

Use the actual filename shown in your folder.

## Notes
- Most files are complete standalone example programs.
- `18_Practice_Templates` contains starter scaffolds with TODO tasks, not completed solutions.
- Some small demonstration programs repeat a concept so you can practice variations; this pack is a large practice collection, not a professionally audited textbook.
- Use a C99-or-newer compiler.
